# KolorLab

Цифровая лаборатория цвета и колеровки: подбор оттенков, визуализация поверхностей, расчёт краски и спецификация проекта.

## Сайт

После успешного GitHub Pages deployment сайт будет доступен по адресу:
[https://niks343.github.io/KolorLab1/](https://niks343.github.io/KolorLab1/).

## Общая база цветов и красок

Пользовательские цвета и краски по умолчанию сохраняются отдельно в данных сайта или Android-приложения. Чтобы перенести свою базу между устройствами:

1. В каталоге оттенков нажмите **«Сохранить базу»**. На сайте скачается JSON-файл; Android-приложение предложит сохранить или передать его через системное меню.
2. На другом устройстве откройте KolorLab, зайдите в каталог оттенков и нажмите **«Загрузить базу»**.
3. Выберите JSON-файл KolorLab. Новые записи добавятся, а записи с совпадающими идентификаторами обновятся без дубликатов. Пользовательские цены красок также переносятся.

Этот файл содержит только добавленные пользователем цвета, краски и цены. Передавать базу можно между сайтом и приложением; копии автоматически по сети не синхронизируются.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

## Проверка и production-сборка

```bash
npm test
npm run build
```

## Android

Проект использует Capacitor. После production-сборки синхронизируйте веб-ресурсы и Android-проект:

```bash
npm run android:sync
npm run android:open
```

Требования и шаги настройки описаны в [ANDROID_SETUP.md](./ANDROID_SETUP.md).
