# KolorLab

Цифровая лаборатория цвета и колеровки: подбор оттенков, визуализация поверхностей, расчёт краски и спецификация проекта.

Каталог красок доступен отдельной вкладкой и группирует продукты по типу: фасадные, интерьерные, 3в1, грунты, пропитки, лаки, эмали и масла. При добавлении краски задаются область применения, колеровка и базы A/C, а также совместимость с металлом, пластиком, деревом, дверями, окнами и откосами. Вкладка «Цвет» не используется: каталог оттенков открывается отдельной кнопкой.

## Общая база цветов и красок

Любой посетитель может добавлять, редактировать и удалять краски и цвета общей пользовательской базы; каждое действие автоматически сохраняется коммитом в отдельный приватный GitHub-репозиторий. Изменения ограничены по частоте с одного IP, но специального входа или разрешений для операций нет — не добавляйте в эту базу конфиденциальные сведения.

Токен GitHub остаётся только в secrets Cloudflare Worker и никогда не передаётся браузеру.

Подключение API и приватной базы описано в [worker/README.md](./worker/README.md). Пока Cloudflare Worker не подключён, общая база недоступна для записи.
Подробности обработки данных — в [PRIVACY.md](./PRIVACY.md).

JSON-экспорт пользовательской базы остаётся доступен для переноса между устройствами.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

## Проверка и production-сборка

```bash
npm test
npm run build
```

## Android

Проект использует Capacitor. После production-сборки синхронизируйте веб-ресурсы и Android-проект:

```bash
npm run android:sync
npm run android:open
```

Требования и шаги настройки описаны в [ANDROID_SETUP.md](./ANDROID_SETUP.md).
