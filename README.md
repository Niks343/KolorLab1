# KolorLab

Цифровая лаборатория цвета и колеровки: подбор оттенков, визуализация поверхностей, расчёт краски и спецификация проекта.

Каталог красок доступен отдельной вкладкой и группирует продукты по типу: фасадные, интерьерные, штукатурки, 3в1, грунты, пропитки, лаки, эмали и масла. Для штукатурки расход и фасовка указываются в килограммах; для остальных материалов — в литрах. При добавлении краски задаются область применения, колеровка и базы A/C, а также совместимые поверхности: минеральные основания, обои, металл, пластик, дерево, двери, окна и откосы. Вкладка «Цвет» не используется: каталог оттенков открывается отдельной кнопкой.

## Общая база цветов и красок

Каталог красок и цветов, карточки клиентов и их проекты синхронизируются через Worker между устройствами. Проекты показываются и управляются внутри карточки соответствующего клиента; общего проекта нет. Для просмотра проекты остаются доступны посетителям сайта, а создание, изменение и удаление требуют шестизначный PIN клиента. Введите PIN в карточке на каждом устройстве: он хранится только в памяти открытой вкладки; Worker также проверяет PIN при каждой записи. Для новых карточек PIN задаётся при создании; карточки, созданные до защиты PIN, остаются доступными только для просмотра. Полный номер телефона хранится в приватном репозитории; API возвращает лишь имя и последние четыре цифры. Требуется согласие клиента. Смотрите [PRIVACY.md](./PRIVACY.md) и не вносите данные без согласия клиента.

В меню «Инструменты» доступны управление цветами и красками, а также отдельный каталог грунтов. Встроенные записи можно редактировать поверх исходной записи или скрыть удалением; изменения общей базы синхронизируются между устройствами.

В совместимых поверхностях красок учитываются радиаторы. Для каждой краски рекомендации по системе материалов настраиваются вручную в форме добавления/редактирования и отображаются в карточке продукта. Для новых пользовательских красок тип блеска выбирается из списка: глянцевая, матовая, полуматовая, полуглянцевая, шелковисто-матовая, глубокоматовая или текстурная.

## Офлайн-работа и синхронизация

После первого посещения приложение кэширует оболочку сайта, а ранее загруженный каталог и проекты остаются доступны из локального хранилища. Пока сеть недоступна, новые и изменённые цвета, краски, клиентские карточки и проекты помещаются в зашифрованную очередь браузера и автоматически отправляются при восстановлении соединения. Индикатор в шапке показывает состояние сети и число ожидающих операций; отклонённая сервером запись остаётся в очереди и сопровождается сообщением об ошибке. Для очереди требуется браузер с IndexedDB и Web Crypto. PIN и номер телефона в очереди защищаются AES-GCM; ключ хранится браузером в IndexedDB, поэтому это защита локального хранилища, а не замена защите устройства или браузера. Очистка данных сайта удалит и неотправленные операции.

## История и качество подбора

Раздел «История» показывает версии цветов, красок и проектов из журнала коммитов общей приватной базы и позволяет восстановить предыдущую версию. Автором считается GitHub-учётная запись, выполнившая запись; метка `device-…` создаётся браузером для различения устройств, но не подтверждает личность. История доступна посетителям так же, как общие записи; в историю клиентских файлов интерфейс не даёт перейти. В каталоге появились подсказки о возможных дубликатах без автоматического удаления, таблица сравнения до трёх материалов и рекомендации совместимых систем по явно заданным поверхностям. Рекомендации эвристические: сверяйте их с технической документацией производителя и пробным нанесением.

Токен GitHub остаётся только в secrets Cloudflare Worker и никогда не передаётся браузеру.

Подключение API и приватной базы описано в [worker/README.md](./worker/README.md). Пока Cloudflare Worker не подключён, общая база недоступна для записи.
Подробности обработки данных — в [PRIVACY.md](./PRIVACY.md).

JSON-экспорт пользовательской базы остаётся доступен для переноса между устройствами.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

## Проверка и production-сборка

```bash
npm test
npm run build
```

## Android

Проект использует Capacitor. После production-сборки синхронизируйте веб-ресурсы и Android-проект:

```bash
npm run android:sync
npm run android:open
```

Требования и шаги настройки описаны в [ANDROID_SETUP.md](./ANDROID_SETUP.md).
