# KolorLab

Цифровая лаборатория цвета и колеровки: подбор оттенков, визуализация поверхностей, расчёт краски и спецификация проекта.

Каталог красок доступен отдельной вкладкой и группирует продукты по типу: фасадные, интерьерные, штукатурки, 3в1, грунты, пропитки, лаки, эмали и масла. Для штукатурки расход и фасовка указываются в килограммах; для остальных материалов — в литрах. При добавлении краски задаются область применения, колеровка и базы A/C, а также совместимые поверхности: минеральные основания, обои, металл, пластик, дерево, двери, окна и откосы. Вкладка «Цвет» не используется: каталог оттенков открывается отдельной кнопкой.

## Общая база цветов и красок

Карточки клиентов и проекты синхронизируются между устройствами и доступны для просмотра всем посетителям. Для новых карточек задаётся PIN из 6 цифр; он требуется для обновления или удаления карточки. Клиенты, созданные до введения PIN, удалить или обновить через сайт нельзя. Проекты общие и могут изменяться любым посетителем. Полный номер телефона хранится в приватном репозитории; API возвращает лишь имя и последние четыре цифры. Требуется согласие клиента. Смотрите [PRIVACY.md](./PRIVACY.md) и не вносите данные без согласия.

В окне управления доступны также встроенные цвета и краски: редактирование сохраняет переопределение поверх исходной записи, а удаление — отметку, скрывающую запись в каталоге. Эти изменения остаются доступными всем посетителям после перезагрузки сайта.

Токен GitHub остаётся только в secrets Cloudflare Worker и никогда не передаётся браузеру.

Подключение API и приватной базы описано в [worker/README.md](./worker/README.md). Пока Cloudflare Worker не подключён, общая база недоступна для записи.
Подробности обработки данных — в [PRIVACY.md](./PRIVACY.md).

JSON-экспорт пользовательской базы остаётся доступен для переноса между устройствами.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

## Проверка и production-сборка

```bash
npm test
npm run build
```

## Android

Проект использует Capacitor. После production-сборки синхронизируйте веб-ресурсы и Android-проект:

```bash
npm run android:sync
npm run android:open
```

Требования и шаги настройки описаны в [ANDROID_SETUP.md](./ANDROID_SETUP.md).
