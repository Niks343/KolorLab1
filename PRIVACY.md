# Конфиденциальность KolorLab

## Общая база цветов и красок

В текущей версии вход по телефону и паролю, регистрация клиентов и клиентские карточки отключены. При добавлении цвета обрабатываются код, название и HEX; при добавлении краски — бренд, название, расход, фасовки, области применения и необязательная цена. Записи отправляются в Cloudflare Worker и сохраняются в приватный GitHub-репозиторий, доступный владельцу репозитория.

Добавление доступно любому посетителю сайта. Worker ограничивает количество отправок с одного IP, но это не является полноценной защитой от целенаправленного злоупотребления. Изменение и удаление существующих записей отключены. Поля форм не должны содержать персональные или конфиденциальные данные.

## Технические данные

Запросы проходят через Cloudflare Worker. Для ограничения частоты Worker временно сохраняет в Cloudflare KV счётчик, связанный с HMAC-хэшем IP-адреса. GitHub token хранится только в секретах Cloudflare и не передаётся браузеру.

## Перед публичным использованием

Владелец сервиса должен указать своё юридическое наименование, контакт для обращений, применимые сроки хранения и правовое основание обработки технических данных, а также проверить это уведомление с учётом применимых требований. Этот шаблон не заменяет юридическую консультацию.
