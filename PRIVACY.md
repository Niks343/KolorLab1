# Конфиденциальность KolorLab

## Общая база цветов и красок

Вход по телефону и паролю отключён. Цвета и краски общей базы (включая встроенные записи, которые посетители изменили или удалили) сохраняются в приватном GitHub-репозитории через Cloudflare Worker. Любой посетитель сайта может добавлять, редактировать и удалять записи; ограничение частоты запросов не предотвращает целенаправленное злоупотребление.

Карточки клиентов также доступны всем посетителям и хранятся в приватном GitHub-репозитории. Для создания карточки требуется подтверждение согласия клиента на хранение телефона. Полный номер телефона сохраняется в репозитории и доступен владельцу репозитория и Worker; публичный API сайта выдаёт только имя клиента и последние четыре цифры номера. Поиск и сохранение карточек выполняются по номеру телефона. Удаление скрывает карточку из текущей версии общей базы и удаляет связанные проекты только в текущем браузере; полный номер может остаться в истории коммитов GitHub. Не вносите данные без согласия клиента.

В общей базе цветов и красок обрабатываются код, название, HEX, бренд, тип, области применения, расход, фасовки и необязательная цена. Проекты и сметы хранятся локально в браузере и не синхронизируются между посетителями.

## Технические данные

Запросы проходят через Cloudflare Worker. Для ограничения частоты Worker временно сохраняет в Cloudflare KV счётчик, связанный с HMAC-хэшем IP-адреса. GitHub token хранится только в секретах Cloudflare и не передаётся браузеру.

## Перед публичным использованием

Владелец сервиса должен указать своё юридическое наименование и контакт для обращений, определить применимые сроки хранения и правовое основание обработки данных, а также проверить это уведомление с учётом применимых требований. Этот шаблон не заменяет юридическую консультацию.
